Object Oriented Programming System (OOPS)

OOPS refers to Object Oriented Programming. It is the programming paradigm that is defined using Objects.

1. What is the need for OOPs?

  • OOPs helps users to understand the software easily, although they don’t know the actual implementation.
  • With OOPs, the readability, understandability, and maintainability of the code increase multifold.
  • Even very big software can be easily written and managed easily using OOPs.

2. What is a Class?

A Class can be understood as a template or a blueprint, which contains some values, known as member data or member & some set of rules, known as behaviours or functions.
So, When an object is created, it automatically takes the data & functions that are defined in the Class.
One can create as many objects as they want based on a Class.
Eg. First a Car's template is created. Then multiple units of Car are created based on that template.

3. What is an Object?

An Object refers to the instance of the Class, which contains the instance of the members & behaviors defined in the Class template.
In the real world, an Object is an actual entity to which a user interacts, whereas class is just the blueprint for that object.
So, the Objects consume space & have some characteristic behaviour.

4. What are the main features/pillars of OOPS?

The main 4 features/pillars of Object Oriented Programming are:

  • Encapsulation
  • Polymorphism
  • Inheritance
  • Abstraction

5. What is Encapsulation?

One can visualize Encapsulation as the method of putting everything that is required to do the job, inside a capsule & presenting that capsule to the user.

By Encapsulation, all the necessary data & methods are bind together & all the unnecessary details are hidden from the normal user.

6. How can we implement Encapsulation?

In C#, Encapsulation can be achieved by using Access Modifiers.

  • Mark fields as private so that they cannot be accessed outside the class.
  • Provide access through public or protected methods or properties as needed.

7. What is Polymorphism?

Polymorphism is composed of 2 words - "poly" means many & "morph" means shapes.

Therefore, Polymorphism refers to something that has many shapes.

In OOPS, Polymorphism refers to the process by which some code, data, method or object behaves differently under different circumstances or contexts.

There are 2 types of Polymorphism:

  • Compile Time Polymorphism
  • Runtime Polymorphism

8. Explain Compile Time Polymorphism.

Compile time Polymorphism means that the method to be executed is determined at compile time.

This is achieved mainly through method overloading.

The compiler decides which method to call based on the number or type of parameters at compile time.

This is achieved mainly through Method Overriding.

12. What is meant by Inheritance?

The term Inheritance means receiving some quality or behaviour from a parent to an offspring.

Inheritance is the mechanism by which an object or class referred to as child class is created using the definition of another object or class referred to as a parent class.

Inheritance not only helps to keep the implementation simpler but also helps to facilitate code reuse.

Example:

Let's take 3 different vehicles - a car, truck & bus.

These 3 are entirely different from one another with their own specific characteristic & behavior.

But in all 3, you will find some common elements like steering wheel, accelerator, clutch, brakes etc.

Though these elements are used in different vehicles, still they have their own features which are common among all vehicles.

This can be achieved through Inheritance.

13. Are there any limitations of Inheritance?

Inheritance needs more time to process, as it needs to navigate through multiple classes for its implementation.

Also, the Classes involved in Inheritance - the base class & the child class are very tightly coupled together.

So, if one needs to make some changes, they might need to do nested changes in both classes.

14. How many types of Inheritance are there in C#?

C# supports 4 types of Inheritance which are as follows:

  • Single Inheritance: A class inherits from one base class.
  • Multi-level Inheritance: A class inherits from a derived class.
  • Hierarchical Inheritance: Multiple classes inherit from a single base class.
  • Multiple Inheritance: C# does not support multiple class inheritance, but you can implement multiple interfaces.

15. What do you mean by Abstraction?

Abstraction is the method of hiding unnecessary details from the necessary ones.

Example: Consider a car. We only need to know how to drive a car & not how the wires are connected inside it.

This is obtained using Abstraction.

Abstraction is typically achieved using abstract classes & interfaces.

16. What is the difference between Abstract Class & Interface?

Abstract Class Interface
It contains both declaration & implementation of methods. It contains only the declaration of methods.
Multiple Inheritance is not achieved by Abstract Class. Multiple Inheritance is achieved by Interface.
It can contain constructor. It does not contain constructor.
It can contain static members. It does not contain static members.
It can contain different type of access modifiers like public, private, protected etc. It only contains public access modifier because everything in the interface is public.
The performance of an abstract class is fast. The performance of an interface is slow because it requires time to search actual method in the corresponding class.
